# Brand illustrations

Editorial images for the README files of this repository. They illustrate the scanner; none of them is scan output or evidence of a result. The measured README media, with the report behind each image, is in [`../readme/`](../readme/README.md).

| File | Shown in |
| --- | --- |
| `scanner-hero-light.webp`, `scanner-hero-dark.webp` | The root README: the animated hero. |
| `scanner-hero-light.gif`, `scanner-hero-dark.gif` | The same hero, for a renderer that does not take WebP. |
| `destinations-light.png`, `destinations-dark.png` | The root README, under "Get started": where the scanner is published. |
| `go-light.png`, `go-dark.png` | `bindings/go/README.md`, and the Go package repository it is staged to. |
| `php-light.png`, `php-dark.png` | `bindings/php/README.md`, and the PHP package repository it is staged to. |

The images were rendered on 18 November 2026 from the design sources of the [QR Code AI](https://qrcode-ai.com/) website, which are kept outside this repository. Only rendered pixels are stored here: no font file and no website source.

The destinations picture and the Go banner show the marks of the platforms where the scanner is published. Those names and logos belong to their owners; here they identify a destination and imply no endorsement.

A README addresses an image by its raw URL with a `?v=` value: the first twelve characters of the file's SHA-256. Replace an image and its `?v=` value together.
