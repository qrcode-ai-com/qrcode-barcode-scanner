# License history

On 14 November 2026, the owner selected MIT for project-authored development source,
bindings, adapters, portable helpers and documentation. The current
[LICENSE](https://github.com/qrcode-ai-com/qrcode-barcode-scanner/blob/main/LICENSE)
and [licensing guide](https://github.com/qrcode-ai-com/qrcode-barcode-scanner/blob/main/LICENSING.md)
describe that source grant. This does not replace a version, rewrite a tag or claim that a
registry has already received new package bytes.

## Earlier published artifacts

Engine 0.11.0 runtime packages and CLI binaries retain their packaged **AGPL-3.0-or-later**
license and the licensing options described at that release's source. Read the
[versioned license](https://github.com/qrcode-ai-com/qrcode-barcode-scanner/blob/v0.11.0/LICENSE)
and [versioned guide](https://github.com/qrcode-ai-com/qrcode-barcode-scanner/blob/v0.11.0/LICENSING.md).
This includes public Flutter 0.11.0 and distributions containing those engine bytes.

The npm MCP adapter 0.3.1 retains its AGPL-3.0-or-later declaration and packaged license.
The portable skill and bundle 0.2.0 retain MIT-0; their separately installed engine keeps
its own license. Go and PHP source tags v0.11.0 retain their original AGPL declarations.
A public source tag is not registry admission.

AUR, AppImage and GHCR distributions built from the public 0.11.0 CLI retain that binary's
original license and notices. New MIT source does not relicense those built files. Their
next versions need MIT-qualified inputs, accurate metadata, new immutable publication records
and clean consumer checks.

## Choosing a source or package

Use the exact archive, packaged license and dependency notices when evaluating an
installation. Current-source MIT examples can still pin an earlier published engine under
different terms. The next engine release and independent agent releases require their own
qualification and publication; a README update is not that publication.

Upstream Apache-2.0, MPL-2.0, MIT and other notices stay attached to their components. The
MIT source decision does not change third-party data, artwork or service terms. Developed by
Thibaut Mélen & Nicolas Cella for QR Code AI, a product of SuperNovae Studio.
