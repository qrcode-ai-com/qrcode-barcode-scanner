# Ask AI providers

The README shortcuts help a reader understand a specific scanner destination,
using a plain-text prompt and its public documentation. They supplement the
README introduction. They do not establish an integration, package qualification,
endorsement or a ranking of model quality.

## Selection reviewed on 13 November 2026

ChatGPT, Claude, Gemini, Grok, Perplexity, Copilot, DeepSeek, Meta AI and Qwen all
appear in the web-product list of [a16z's seventh consumer AI report, published
5 October 2026](https://a16z.com/100-gen-ai-apps-7/). The report ranks web/mobile
products using traffic measures, which do not establish the best answer for a
scanner task or count every use inside other applications. These nine assistants
provide a bounded selection of widely used services, rather than an exhaustive
catalogue or an unmeasured performance comparison.

## Opening and copying a prompt

Gemini uses the [consumer Gemini website](https://gemini.google.com/), as described
in [Google's application guide](https://support.google.com/gemini/answer/13275745).
Its link contains no invented prefill parameter and opens no developer studio.
The links for [Copilot](https://copilot.com/),
[DeepSeek](https://chat.deepseek.com/), [Meta AI](https://www.meta.ai/) and
[Qwen](https://qwen.ai/) likewise open their official sites. Copy the complete
plain-text prompt from the expanded README code block, then paste it into the
chosen assistant. On GitHub, the code block provides its own copy control.

The retained ChatGPT, Claude, Grok and Perplexity links carry the public prompt in
their URL. Provider behavior varies: a link can prefill a composer, require
sign-in, or start a query. A provider may not be available for a particular account
or region. The readable prompt is always available as a fallback. No extension,
new account or automatic editor installation is required by the documentation.

The generator makes no provider request. The prompt includes public context only
and asks for sources, prerequisites and limitations without inventing installation
commands, benchmark results or comparisons. Check any answer against the original
documentation. Existing published package archives remain unchanged.
