<Note>
The five runtime entry points below are public in **0.11.0**: Rust core, CLI,
Node native, browser WASM and Python. Install and import the new package names
together. Native Node platform dependencies are selected automatically; the
browser package uses one portable WASM. See the
[migration guide](/guides/migrate-to-qrcode-barcode-scanner) for old-name installs.
</Note>

<Tabs>
  <Tab title="Rust">
    ```bash
    cargo add qrcode-barcode-scanner@=0.11.0
    ```

    ```rust
    use qrcode_barcode_scanner::{ImageInput, ScanProfile, Scanner};

    let scanner = Scanner::builder().profile(ScanProfile::Full).build();
    let report = scanner.scan(ImageInput::encoded(&image_bytes))?;

    match report.detections.first() {
        Some(d) => {
            println!("{} (engines: {:?})", d.content.text, d.engines);
            if let Some(score) = &report.score {
                println!("score {}/100 ({:?})", score.value, score.grade);
            }
        }
        None => println!("no QR found"), // a RESULT, not an error
    }
    for hint in &report.hints {
        println!("hint: {hint:?}"); // feed back to your generator
    }
    ```

    Camera frames skip the PNG roundtrip: `ImageInput::rgba8(&frame, w, h)`.
  </Tab>

  <Tab title="Node">
    ```bash
    npm install --save-exact @qrcode-ai-com/qrcode-barcode-scanner@0.11.0
    ```

    ```js
    import { scan } from "@qrcode-ai-com/qrcode-barcode-scanner";

    // async on the libuv pool — never blocks the event loop
    const report = await scan(imageBuffer, {
      profile: "full",     // full | fast | frame
      budgetMs: 1500,      // bound the worst case (0 = unbounded)
      maxDimension: 4096,  // tighten limits for untrusted uploads
      maxPixels: 16_000_000,
    });

    if (report.detections.length) {
      const d = report.detections[0];
      // score null + trace.budget_exhausted = not judged within the budget
      console.log(d.content.text, d.payload.kind, report.score?.value);
    }
    ```

    Full TypeScript types ship in the package (`ScanReport` and friends).
  </Tab>

  <Tab title="Browser (WASM)">
    ```bash
    npm install --save-exact @qrcode-ai-com/qrcode-barcode-scanner-wasm@0.11.0
    ```

    ```ts
    import init, { scan_image } from "@qrcode-ai-com/qrcode-barcode-scanner-wasm";

    await init(); // loads the .wasm via import.meta.url

    const bytes = new Uint8Array(await file.arrayBuffer());
    // args: bytes, profile, maxDimension, maxPixels, budgetMs
    const report = scan_image(bytes, "full", undefined, undefined, 1500);

    console.log(report.detections[0]?.content.text, report.score?.value);
    ```

    <Warning>
    The scan runs synchronously **on the calling thread**. In UI contexts,
    always pass a `budget_ms` (1500 ms is the verify-flow default) or run
    it in a Worker. A report the budget cut says so —
    `trace.budget_exhausted === true` — and a `null` score beside a
    detection then means "not judged", never 0.
    </Warning>

    Vite/Nuxt: exclude the package from pre-bundling —
    `optimizeDeps: { exclude: ["@qrcode-ai-com/qrcode-barcode-scanner-wasm"] }`,
    using the installed 0.11 package name.
  </Tab>

  <Tab title="CLI">
    ```bash
    cargo install qrcode-barcode-scanner-cli --version 0.11.0 --locked

    qrscan image.png            # full ScanReport JSON on stdout
    qrscan image.png --pretty   # human summary (incl. the ISO grade card)
    qrscan image.png -s         # bare score value for scripts
    qrscan image.png -s --budget-ms 0   # unbounded: reproducible, never cut
    # exit codes: 0 found · 1 none · 2 invalid input/usage · 3 (-s) not judged within the budget
    ```

    From 0.11.0, `qrscan` ships in the `qrcode-barcode-scanner-cli` crate. Both
    crates install the same `qrscan` command: uninstall `qrcode-ai-scanner-cli`
    before installing the new one.
  </Tab>

  <Tab title="Python">
    Install the public PyPI package; a matching wheel needs no Rust toolchain:

    ```bash
    python -m pip install qrcode-barcode-scanner==0.11.0
    ```

    ```python
    import qrcode_barcode_scanner as q

    report = q.scan(image_bytes, "full")   # → ScanReport dict; the scan releases the GIL
    dets = report["detections"]
    if dets:
        d = dets[0]
        print(d["content"]["text"], d["payload"]["kind"], (report["score"] or {}).get("value"))
    ```

    `abi3` wheel tags declare CPython 3.8 → 3.14 compatibility; this is not a
    test of every interpreter version. Types ship (`qrcode_barcode_scanner.pyi`).
  </Tab>
</Tabs>

Mobile bindings use the same report contract, but Flutter is not published,
Kotlin/JitPack is not qualified and Swift requires a local build. See their
[API pages](/api/mobile) for source-build instructions.

## Choosing a profile

| Profile | Budget | Use it for |
|---|---|---|
| `full` | 4 s (override with budget) | generator quality gate, verify flows — **the only profile that decodes the blob/dot template class** |
| `fast` | 800 ms | upload tools where latency beats recall |
| `frame` | 80 ms | per-frame camera loops (no scoring) |

Every budget is a default you can override (`budget_ms` / `budgetMs` /
`--budget-ms`); `0` is unbounded and the only strictly reproducible mode.
`trace.budget_exhausted` tells a final report (`false`) from one the budget
cut (`true`).

<Tip>
The report's `trace.stages` tells you exactly which stage decoded (or how
far the ladder walked before giving up) — log it when debugging recall.
</Tip>
