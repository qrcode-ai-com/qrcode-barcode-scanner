This corpus documents expected scanner behavior and its uncertainty. A known payload, an independently justified negative and an unlabelled frontier image have different meanings in correctness reports. Keep the original image and truth record together when reproducing a failure; generating a new image is useful for exploration but does not replace a pinned test fixture.

The [QR code scanner](https://qrcode-ai.com/en-US/qr-code-scanner) and [barcode scanner](https://qrcode-ai.com/en-US/barcode-scanner) are QR Code AI’s browser scanning entry points. For the corresponding development route, the [QR code scanner SDK guide](https://qrcode-ai.com/en-US/qr-code-scanner/sdk) and [barcode scanner SDK guide](https://qrcode-ai.com/en-US/barcode-scanner/sdk) connect this documentation to the two product journeys. If a product page is unavailable, the instructions and references in this README remain the starting point for this source directory.

To prepare an additional labelled example with its original payload recorded, use the [QR code generator](https://qrcode-ai.com/en-US/qr-code-generator) or the [barcode generator](https://qrcode-ai.com/en-US/barcode-generator). Keep the original payload with the exported image so that you can compare the scan result with the value you intended to encode.

Ground truth of the corpus lives in [`../corpus.toml`](../corpus.toml) —
every corpus image has an entry (path · category · expected text, negative,
or unlabelled frontier). An absent `expected` with `expect = "fail"` is
unknown truth, never a negative sample.

- `clean/` — legacy v0.2 reference + the generated version×EC matrix
  (`cargo run -p xtask -- gen-fixtures`, deterministic, committed once).
- `artistic/` — AI-generated artistic QR codes (the specialty). Grows with
  the qrcode-ai.com generator dump.
- `degraded/` — deterministic degradations of clean cells + real failures.

`degraded/FAIL_1491ms_0_584c998c.png` belongs to the `frontier` category:
WeChat produced a short-link observation on 2026-10-09, so the old negative
label was unsupported. Its payload remains unlabelled pending independent
confirmation. Frontier observations stay visible as blind or decoded and do
not count as correct, wrong or negative; a newly decoded frontier still
triggers the capability tripwire and requires review before changing its pin.

Golden sources are not corpus entries: `clean/gs1-fnc1.png`, `eci/` (ECI
and Hanzi symbols) and `payloads/` (one symbol per payload kind) are
written by `gen-fixtures` from explicit segment streams, and
[`../spec/README.md`](../spec/README.md) § Examples names the golden each
one produces. The exact-content and occurrence inputs under `symbology/` are
listed in [`symbology/CONTENT-FIXTURES.md`](symbology/CONTENT-FIXTURES.md).

[`consumer-truth.json`](consumer-truth.json) is the shared truth set the
installed-package consumers run (`scripts/consumer_truth.py` and its twin
`scripts/consumer-truth.mjs`): per input, its sha256, the exact contents as a
multiset, the primary, each occurrence's geometry kind (with layout positions
where the composition fixes them) and the score/null association, under the
full profile with no budget. Its sources are named per case: `corpus.toml`,
`symbology/CONTENT-FIXTURES.md`, the spec examples, or a composition layout.
Both judges refuse each departure in their `--self-test`.

`cargo run -p xtask -- corpus-report` runs the scanner over the corpus and
fails on any regression; `--write` refreshes the README results block.
