# Rebuilding the QR Code & Barcode Scanner add-on from source

This is the source package of the QR Code & Barcode Scanner browser extension, version 0.1.0.
It builds the Firefox add-on and the Chrome and Edge packages. These notes are written for a
Firefox Add-ons reviewer who wants to rebuild the uploaded add-on and compare it.

## What you need

- Node.js 22.19 or later on the 22 line, or Node.js 24 or later, with the npm that comes with it.
  The packages were built with Node.js 22.22.2 and npm 10.9.7, and CI gets the same bytes with
  Node.js 22 and 24 on Linux, macOS and Windows.
- Any operating system that runs Node.js: Linux, macOS or Windows.
- Network access to the npm registry, for one package.

No bundler, compiler, minifier or transpiler runs. The build does not need a browser.

## Build

From the folder that holds this file:

```sh
npm ci --omit=dev --ignore-scripts
npm run build-for-amo
```

`npm ci` installs exactly one package from `package-lock.json`:
`@qrcode-ai-com/qrcode-barcode-scanner-wasm` 0.11.0, checked against its `sha512` integrity.
`--omit=dev` leaves out the test tools (Playwright and web-ext), and `--ignore-scripts` runs no
install script. `npm run build-for-amo` runs `node scripts/build.mjs`. It writes:

- `build/firefox/`, the unpacked add-on, and `build/qrcode-barcode-scanner-firefox-0.1.0.zip`;
- the same for `chrome` and `edge`;
- `build/qrcode-barcode-scanner-source-0.1.0.zip`, this source package;
- `build/build-receipt.json`, with the size and SHA-256 of every archive.

Compare `build/firefox/` with the files of the uploaded add-on: they are the same files, and the
zip has the same bytes: every entry carries one fixed date, so neither the clock nor the time zone
changes it. `build/build-receipt.json` and `build/SHA256SUMS` give the SHA-256 of each archive.
A signed copy from Firefox Add-ons also holds the signature that Mozilla adds under `META-INF/`.
`node scripts/inspect.mjs build` checks each archive: its file list, its manifest, the pinned
WebAssembly module, and that no script builds code from text or loads it from the network.

## Where each file of the add-on comes from

| Add-on file | Source |
| --- | --- |
| `background.js`, `scanner.html`, `scanner.css`, `scanner.js`, `scanner-worker.js`, `results.js` | `src/`, copied as written |
| `manifest.json` | written by `scripts/manifest.mjs` |
| `icons/icon-*.png` | drawn by `scripts/icons.mjs`; no image file is in the source |
| `LICENSE`, `NOTICE.md`, `PROVENANCE.json` | `LICENSE`, and written by `scripts/build.mjs` |
| `vendor/qrcode-barcode-scanner-wasm/*` | copied unchanged from `node_modules/@qrcode-ai-com/qrcode-barcode-scanner-wasm/` |

The build stops if the installed scanner package is not version 0.11.0, if its lockfile entry
differs, or if the SHA-256 of its WebAssembly module is not
`a5d684cec3863e210bbb7f473267dcf07a8321ff57bf17a321af58f5d261ab68`. That value is in
`package.json` (`config.wasmSha256`) and in the package's own `build-info.json`.

## The WebAssembly module

`qrcode-barcode-scanner_bg.wasm` is the scanner engine. It is the file of the published npm
package, not a file built here. The package is the official release of the engine at
<https://www.npmjs.com/package/@qrcode-ai-com/qrcode-barcode-scanner-wasm/v/0.11.0>.

Its Rust source is the public repository
<https://github.com/qrcode-ai-com/qrcode-barcode-scanner-rust> at tag `v0.11.0`, revision
`176ac96ef16ee330dbfc6ada10327d0b4e23a8b2`. That repository's `scripts/build-wasm.sh` is the
recipe. `build-info.json` in the package records the revision, the SHA-256 of the compiled
inputs, and the toolchain: rustc 1.99.1, wasm-pack 0.13.1, wasm-bindgen 0.2.126 and wasm-opt
version 130, for `wasm32-unknown-unknown` without SIMD. `qrcode-barcode-scanner.js` and
`auto.js` are the package's JavaScript glue, generated by wasm-bindgen and not minified.

The add-on compiles the module in a worker with `WebAssembly`, which the manifest's policy
`script-src 'self' 'wasm-unsafe-eval'; object-src 'self'` allows. No code is loaded from the
network.

## Checks in this source

```sh
npm ci --ignore-scripts
npm run build
npm test                    # Node unit tests, no browser
npm run inspect             # the archive checks above
npm run lint:firefox        # Mozilla's add-on linter, through web-ext
npm run test:chromium       # the Chrome build in Playwright's Chromium
npm run test:firefox-addon  # the Firefox zip installed in Firefox (FIREFOX=/path/to/firefox)
npm run test:firefox-page   # the Firefox build's page in Playwright's Firefox
npm run test:reproduce      # rebuild from the source zip and compare the archives
```

The browser tests need Playwright's browsers:
`node node_modules/playwright/cli.js install chromium firefox`.
