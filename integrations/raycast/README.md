This Raycast extension reads the QR codes and barcodes in an image on your Mac. Select the image in Finder, or copy the image file, then run **Scan Image for Codes**. The codes appear in a list, and you copy or paste the exact text of each one. The scan runs on your Mac with `qrscan`, the scanner's command line, and nothing is sent anywhere.

The [QR code scanner](https://qrcode-ai.com/en-US/qr-code-scanner) and the [barcode scanner](https://qrcode-ai.com/en-US/barcode-scanner) of QR Code AI read the same codes in a browser. The [QR code scanner guide for Raycast](https://qrcode-ai.com/en-US/qr-code-scanner/integrations/raycast) and the [barcode scanner guide for Raycast](https://qrcode-ai.com/en-US/barcode-scanner/integrations/raycast) show this extension at work, step by step.

To make a test image, encode a known text with the [QR code generator](https://qrcode-ai.com/en-US/qr-code-generator) or the [barcode generator](https://qrcode-ai.com/en-US/barcode-generator), save the picture, select it in Finder and run the command. The list should give back exactly the text you encoded, leading zeros included.

The extension is not in the Raycast Store yet. Until it is, run it from this folder, as written below.

The picture shows the three steps of the package route. In Raycast they are:

1. Install `qrscan` once, then the extension. The extension finds `qrscan` by itself.
2. Select an image in Finder, or copy an image file, and run **Scan Image for Codes**.
3. Read the list. Press Enter to copy a code's text, or choose **Paste Text** or **Copy All Texts** in the actions.

## Install

Install `qrscan` with the [QR Code AI Homebrew tap](https://github.com/qrcode-ai-com/homebrew-tap):

```sh
brew install qrcode-ai-com/tap/qrscan
```

The extension looks for `qrscan` in `/opt/homebrew/bin`, `/usr/local/bin` and `~/.cargo/bin`. If yours is elsewhere, set **qrscan Path** in the extension's preferences.

Then run the extension from this folder with Node.js 22 or later and Raycast open:

```sh
npm ci
npm run dev
```

`npm run dev` adds the extension to Raycast in development mode. Once the extension is in the store, you will find it in the Raycast Store under the same name.

## Use

**Scan Image for Codes** takes the first PNG, JPEG, WebP or GIF image selected in Finder. When Finder is not in front, it takes the image file on the clipboard instead.

Each code is one item of the list: its text, its format, and a tag when some of its bytes are not text. Text on several lines shows on one line in the list, with `↵` where a line ends; the copied text keeps its line breaks. The actions are:

- **Copy Text**, the default: the exact text of the code.
- **Paste Text**: the same text, into the app in front.
- **Copy All Texts**: every text of the image, one per line.

Decoded text comes from an image anyone can make. The extension only shows, copies and pastes it: it never opens a link it reads.

**Scan Profile** in the preferences sets how long `qrscan` searches. Full, the default, searches longest and reads the most damaged codes. Fast and Frame stop sooner; when they run out of time, the list says so, because an empty result is then not final.

When `qrscan` is missing, the extension says where it looked, and offers to copy the install command or open the install guide. A file that is not an image gives the reason `qrscan` reports.

Codes of different formats in one image come back in one report.

- QR: QR Code, Micro QR, rectangular Micro QR (rMQR)
- Matrix and stacked: Data Matrix, Aztec, PDF417, MaxiCode
- Retail: EAN-13, EAN-8, UPC-A, UPC-E
- Other linear: Code 128, Code 39, Code 93, Codabar, ITF, GS1 DataBar, GS1 DataBar Expanded, Telepen

`qrscan` reads PNG, JPEG, WebP and GIF files; it does not read HEIC, TIFF or BMP. The engine's [supported formats](https://github.com/qrcode-ai-com/qrcode-barcode-scanner-rust#supported-formats) section states the known limits.

## Tests

In this folder:

```sh
npm ci
npm run typecheck
npx eslint src
npx prettier --check src package.json
npx ray build --non-interactive --environment dist --output /absolute/empty/folder
QRSCAN=/opt/homebrew/bin/qrscan npm test
```

`npm test` drives the command against a stand-in for the Raycast API. It checks how the extension finds `qrscan`, the arguments it passes, every way `qrscan` can end (codes, no code, an unreadable file, a missing program, a crash, a timeout, output that is not a report) and the list shown for each. With `QRSCAN` set, it also scans the mixed fixture in the fast, frame and full profiles, from a Finder selection and from the clipboard. CI downloads the published `qrscan` with the checked installer of the GitHub Action and sets `QRSCAN_RAYCAST_LIVE=required`, so a missing `qrscan` fails instead of skipping.

`ray build` needs no Raycast account. `ray lint` is not part of the tests, because it asks the Raycast store about the author.
