This Arch Linux recipe installs the released upstream CLI rather than compiling a different scanner. Review the PKGBUILD and verified source before installation, then check the installed version and the mixed-code result. The package-manager route manages qrscan on the system; image capture and any application interface remain the caller’s responsibility.

The [QR code scanner](https://qrcode-ai.com/en-US/qr-code-scanner) and [barcode scanner](https://qrcode-ai.com/en-US/barcode-scanner) are QR Code AI’s browser scanning entry points. For the corresponding development route, the [QR code scanner command line guide](https://qrcode-ai.com/en-US/qr-code-scanner/cli) and [barcode scanner command line guide](https://qrcode-ai.com/en-US/barcode-scanner/cli) connect this documentation to the two product journeys. If a product page is unavailable, the instructions and references in this README remain the starting point for this source directory.

To prepare a saved image for the installed Arch command, use the [QR code generator](https://qrcode-ai.com/en-US/qr-code-generator) or the [barcode generator](https://qrcode-ai.com/en-US/barcode-generator). Keep the original payload with the exported image so that you can compare the scan result with the value you intended to encode.

`qrcode-barcode-scanner-bin` installs the upstream `qrscan` executable for
x86_64 Arch Linux. The recipe verifies the official
[0.11.0 release archive](https://github.com/qrcode-ai-com/qrcode-barcode-scanner/releases/tag/v0.11.0)
and keeps the executable bytes unchanged. It conflicts with other packages
providing `qrscan`, including the unrelated AUR `qrscan-bin`.

Install from the [public AUR package](https://aur.archlinux.org/packages/qrcode-barcode-scanner-bin)
on Arch Linux x86_64.

```sh
git clone https://aur.archlinux.org/qrcode-barcode-scanner-bin.git
cd qrcode-barcode-scanner-bin
makepkg -si
```

Check `qrscan --version` and scan the
[mixed QR and Code 128 sample](https://github.com/qrcode-ai-com/qrcode-barcode-scanner/blob/v0.11.0/fixtures/symbology/mixed-code128-qr.png)
to exercise both formats.
