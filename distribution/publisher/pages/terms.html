Software licences

QR Code AI publishes the QR Code & Barcode Scanner as open-source software. This page lists the licence of each published part. The licence texts are the only terms; this page adds nothing to them and removes nothing from them.

The source code

The project-authored source in the scanner's repository is under the MIT License: the engine, its bindings, the command-line program, the integrations, the agent skill and the documentation. The licence file carries the copyright notice. The licensing guide explains what the MIT grant covers.

Published releases

A published file keeps the licence it was packaged with. The source moved to MIT after these releases, and that change does not relabel them:

  • The engine release 0.11.0, in all its runtime packages and command-line programs, is under the GNU Affero General Public License, version 3 or any later version (AGPL-3.0-or-later). So is every distribution that contains those engine files.
  • The MCP server 0.3.1 on npm is under AGPL-3.0-or-later.
  • The agent skill 0.2.0 and the OpenClaw plugin bundle 0.2.0 are under MIT-0. The engine they install separately keeps its own licence.
  • The VS Code extension, the Obsidian plugin, the browser extension, the Canva app, the Adobe Express add-on and the WordPress plugin contain the published WebAssembly engine 0.11.0, and the HTTP service's container image contains its Node.js engine 0.11.0. Their own source is MIT and the engine inside them stays under AGPL-3.0-or-later; the licence notes of each one give the licence of the package as a whole.
  • The other integrations are MIT and install or run a published engine release, which keeps its own licence.

The licence history records each of these grants, and the repository keeps the exact AGPL-3.0 text those releases carry.

Third-party components

Third-party code keeps its own licence and notices. The copied rxing and ZXing reader source stays under the Apache License 2.0, as THIRD-PARTY.md describes, and the dependencies keep the licences they declare.

Warranty and liability

Each of these licences provides the software as it is, without warranty of any kind, and contains its own limitation of liability. Read the licence of the file you use for the exact wording.

The QR Code AI service

These licences cover the scanner's software only. They do not cover the QR Code AI service at qrcode-ai.com, which is a separate product.
