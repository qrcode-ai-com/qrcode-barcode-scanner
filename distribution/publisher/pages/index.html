QR Code & Barcode Scanner

QR Code AI publishes an open-source scanner that reads QR codes and barcodes from images. One engine runs inside every integration below, on the device or server that runs it.

The source code, the issues and the release files are in the scanner's repository. The pages of this site say what the scanner reads and sends (privacy), under which licences it is published (licences) and where to ask for help (support).

Engine packages

Applications can also call the engine directly. Version 0.11.0 is published as a Rust crate, a Python package, an npm package and a PHP package, with a Flutter plugin on pub.dev and the command-line program on the release page.

The agent skill on this site

This site serves the scanner's agent skill at /.well-known/agent-skills/index.json, the Agent Skills discovery index, with the older layout at /.well-known/skills/index.json. The archive is the file of the agents-v0.2.1 release, byte for byte, and the index carries its SHA-256 digest.
