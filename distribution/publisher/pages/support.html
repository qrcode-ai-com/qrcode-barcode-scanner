Support

Support for the QR Code & Barcode Scanner happens in the open, in its repository on GitHub.

Questions and problems

Ask a question, report a bug or suggest a change in the scanner's issues. Search the open issues first. A useful report names the integration or package and its version, the operating system or host, what you expected and what happened. Attach the image only if it holds nothing private.

Each integration has a README in its source folder with its installation, settings and removal.

Security

Do not report a vulnerability in a public issue. Report it privately, as the security policy describes.

Releases

Every release, with its files and checksums, is on the releases page.
