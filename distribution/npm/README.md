Platform-specific Rust addon for `@qrcode-ai-com/qrcode-barcode-scanner`.
The main package selects the compatible addon for your operating system and
processor. Its documentation contains the JavaScript API and usage examples.

This addon runs the engine used by [QR Code AI](https://qrcode-ai.com/en-US/qr-code-scanner/sdk/nodejs) for QR verification.
