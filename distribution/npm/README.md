This native platform dependency is selected automatically by the parent Node.js package for its operating system and processor. Application code imports the parent package and uses its documented API. The addon is not a separate JavaScript SDK; installing an incompatible platform package manually does not add support for that platform.

The [QR code scanner](https://qrcode-ai.com/en-US/qr-code-scanner) and [barcode scanner](https://qrcode-ai.com/en-US/barcode-scanner) are QR Code AI’s browser scanning entry points. For the corresponding development route, the [QR code scanner Node.js guide](https://qrcode-ai.com/en-US/qr-code-scanner/sdk/nodejs) and [barcode scanner Node.js guide](https://qrcode-ai.com/en-US/barcode-scanner/sdk/nodejs) connect this documentation to the two product journeys. If a product page is unavailable, the instructions and references in this README remain the starting point for this source directory.

To prepare a sample image for the parent Node.js package, use the [QR code generator](https://qrcode-ai.com/en-US/qr-code-generator) or the [barcode generator](https://qrcode-ai.com/en-US/barcode-generator). Keep the original payload with the exported image so that you can compare the scan result with the value you intended to encode.

Platform-specific Rust addon for `@qrcode-ai-com/qrcode-barcode-scanner`.
The main package selects the compatible addon for your operating system and
processor. Its documentation contains the JavaScript API and usage examples.

This addon runs the engine used by [QR Code AI](https://qrcode-ai.com/en-US/qr-code-scanner/sdk/nodejs) for QR verification.
