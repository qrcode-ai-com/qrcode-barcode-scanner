This directory prepares and tests a Windows Chocolatey package around the published upstream executable. The local consumer verifies command creation, mixed-image decoding and removal. A successful local package test is distinct from moderator approval and public catalogue installation; keep the source and executable hashes with the resulting receipt.

The [QR code scanner](https://qrcode-ai.com/en-US/qr-code-scanner) and [barcode scanner](https://qrcode-ai.com/en-US/barcode-scanner) are QR Code AI’s browser scanning entry points. For the corresponding development route, the [QR code scanner command line guide](https://qrcode-ai.com/en-US/qr-code-scanner/cli) and [barcode scanner command line guide](https://qrcode-ai.com/en-US/barcode-scanner/cli) connect this documentation to the two product journeys. If a product page is unavailable, the instructions and references in this README remain the starting point for this source directory.

To prepare a known Windows test image, use the [QR code generator](https://qrcode-ai.com/en-US/qr-code-generator) or the [barcode generator](https://qrcode-ai.com/en-US/barcode-generator). Keep the original payload with the exported image so that you can compare the scan result with the value you intended to encode.

The `qrcode-barcode-scanner` package carries the released `qrscan` 0.11.0
executable for x64 Windows. Chocolatey creates the command shim and removes it
at uninstall. The build verifies the official ZIP and executable hashes, keeps
the original source and license records, and adds Chocolatey's verification
files. See the [original Windows release](https://github.com/qrcode-ai-com/qrcode-barcode-scanner/releases/tag/v0.11.0)
and the [CLI documentation](../cli/README.md).

On a disposable x64 Windows host with Chocolatey CLI 2.x and PowerShell 7,
run the consumer from an elevated shell. It creates the package in the given
directory, installs it from that local directory, verifies the shim, scans the
mixed QR and Code 128 fixture in all three profiles, and uninstalls it.

```powershell
./distribution/chocolatey/test.ps1 -WorkDirectory "$env:TEMP/qrscan-chocolatey-check"
```

The generated `receipt.json` records the exact package hash and scan results.
Community Repository admission requires a separate submission, moderation, and
a clean install from the public feed. This recipe and its local test do not
establish availability in that feed.
