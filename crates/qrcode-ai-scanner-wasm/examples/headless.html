Scan an image

This page decodes an image you choose with the scanner package it is served from. The image is decoded in a worker on this device: it is never uploaded, and the page requests nothing outside the package folder. Decoded links are shown as text and never opened.

Image and profile

You can also drop an image file on this box.

full runs every stage and judges scannability; fast skips the deep QR stages and scores less; frame only decodes, as for camera frames. Each scan runs to its end, without a time budget. Changing the profile scans the chosen image again.
