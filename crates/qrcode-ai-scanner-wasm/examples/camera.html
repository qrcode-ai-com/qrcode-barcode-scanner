Scan with the camera

This page scans camera frames with the scanner package it is served from. The camera starts only when you press Start the camera. Each frame is decoded in a worker on this device and never uploaded. Decoded values are shown as text: a decoded link is never opened, and checking where it leads is off unless you turn it on below.

The effects dim and blur the picture around the codes the scanner located precisely, and draw a halo along their outlines. They change only what you see: the scanner reads the frames as the camera sends them.

Link destinations

Off by default. When on, the readout of a decoded http(s) link offers a Check destination button, and nothing is checked until you press it. A check is a real request from this browser to the link, and to every redirect the browser follows: up to 20, to any host, one on a private network included. Before the request leaves, the page vets only the link itself; each redirect is left to the browser. A check can count a visit or use up a one-time link. Its result is what the browser lets the page see of those requests, shown as text; it is not a safety verdict, and nothing is opened.

Keyboard

Tab moves through the controls; Enter or Space presses a button. In the list of codes, the arrow keys, Home and End move between codes, Enter or Space selects one, and a digit selects codes 1 to 9 while the focus is in the list or the readout. After you select a code, Escape returns to automatic selection.
